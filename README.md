-------------------------=====Sistema=====------------------------- 

- Oracle Linux 9.8 
ISO: OracleLinux-R10-U1-x86_64-boot-uek.iso
Endereço do download: https://yum.oracle.com/ISOS/OracleLinux/OL10/u1/x86_64/OracleLinux-R10-U1-x86_64-boot-uek.iso
